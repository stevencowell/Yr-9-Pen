# Pen website change requests — admin guide

## Before staff use it

1. Open the private [Pen website change request document](https://docs.google.com/document/d/1E6rJTa34n_yv9kkZstta99LEAjwbbUIZnhtyYI3x19U/edit).
2. Share it only with the relevant staff Google group and nominated administrators as editors. Do not select **Anyone with the link**.
3. Each administrator opens **Tools → Notification settings** and selects **Added or removed content**.
4. Test access with one authorised staff account before publishing the website change.

## Staff workflow

From any Pen website page, select **Suggest a change**. The site copies that exact page address and opens the staff document. Staff paste the page address, select **ADD**, **UPDATE** or **DELETE**, type a short request and optionally paste a cropped screenshot.

Staff must not include student names, student work, marks, email messages or other sensitive information.

## Admin workflow

- Mark each request **RECEIVED**, **NEEDS CLARIFICATION**, **APPROVED**, **LIVE** or **NOT PROCEEDING**.
- Confirm unclear requests in the document before changing the site.
- Treat **LIVE** as meaning the change has been published and checked on the intended public page, not merely edited locally or pushed to GitHub.
- Move finished requests under **Completed requests** so the open list stays short.

## Side-by-side view

The site attempts to open the request document in its own window. On Windows, press **Windows + Right Arrow**, then choose the Pen website for the left side. Browser security prevents the website from reliably arranging both windows automatically.
