# Year 9 Pen Guided Course

A complete, browser-based Industrial Technology Timber guided course for the Year 9 Pen project.

## Student pathway

- ten paired-week modules covering Weeks 1–20
- three project-specific theory sections per module
- twelve multiple-choice knowledge checks per module, with hints and immediate feedback
- four scaffolded written responses per module, with feedback prompts and model responses
- browser/device-local autosave and Print / Save PDF evidence
- a progressive twelve-card project folio with local backup and restore

## Source authority

Project facts are based on the approved Pen Making resource, assessment and program material. The course directs students back to the approved working information and teacher checkpoints whenever a value or setup must be confirmed. It does not add unverified project dimensions, component schedules or machine settings.

Visual provenance and intended use are recorded in [ASSET-SOURCES.md](ASSET-SOURCES.md).

## Hosting

This static site is designed for GitHub Pages from the repository root. Open `index.html` locally through a web server for testing.
